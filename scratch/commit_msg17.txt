refactor(signal): 매트릭스 가산 점수 균등화 + 활성 조건 다중화

문제: 기존 매트릭스가 MA/정배열에 편중 (80점/100점)
- 골든크로스 +30 / 정배열 +25 / ma20우상향 +15 = MA 관련 80점
- 다른 11개 요소 (ADX/캔들/OBV/스윙/Polarity/라운드 등) = 20점
- → 한미반도체(역배열) = 13점으로 매수 비추천, MA 외 신호 무시

해결: 14개 요소 균등 분배 (~7점) + 활성 조건 4가지 다중화

=== 가산 점수 균등화 (MA/정배열 축소) ===
| 요소 | 이전 | 변경 |
|---|---:|---:|
| 골든크로스(방금) | +30 | +10 |
| 골든크로스(3일 내) | +20 | +7 |
| 정배열 | +25 | +10 |
| ma20우상향 | +15 | +5 |
| ma60우상향 | +10 | +5 |
| 거래량 | +15 | +5 |
| 60일 고가 5% | +5 | +3 |
| POC | +15 | +7 |
| 지지선 | +10 | +5 |
| ADX 강상승 | +10 | +7 |
| ADX 강하락 | -5 | -3 |
| 캔들 강상승 | +20 | +10 |
| 캔들 강하락 | -15 | -7 |
| OBV UP | +8 | +5 |
| OBV 강세다이 | +12 | +7 |
| 스윙로우 | +5 | +5 |
| Polarity | +5 | +5 |
| 라운드 | +5 | +5 |

=== 활성 조건 다중화 (4가지 신호) ===
buy1Active = !suppressed && (
  buy1ByMa         // 골든크로스 OR (정배열+거래량+ma20우상향)
  || buy1ByMomentum // 강한상승캔들 + ADX STRONG UP + OBV UP
  || buy1BySupport  // (POC/지지선/라운드) + OBV UP — MA 무관
  || buy1ByStructure // Polarity 지지전환 + 캔들반전
)

buy2Active = !suppressed && (
  buy2ByPullback  // 눌림목(MA5/MA20) + 양봉 + 거래량감소 + ma20우상향 + 60일선 위
  || buy2ByDeep   // (POC/지지선) + 강한캔들 + OBV UP — MA 무관
)

buy1Suppressed = 강한하락캔들 + ADX STRONG DOWN
buy2Suppressed = buy1Suppressed 동일

=== 시뮬레이션 결과 (8/14 종가) ===

한미반도체 (042700, 데드크로스)
  - buy1ByMa: false (정배열 X)
  - buy1ByMomentum: false (ADX 약, 캔들 X)
  - buy1BySupport: TRUE ⭐ (라운드 210,000 근접 + OBV UP) → 활성!
  - buy1ByStructure: false
  - 1차매수 13 → 10점 ✅ 활성
  - 이유: ADX 약추세(관망) + OBV 상승(수급 유입) + 라운드 210,000(심리적 지지)

셀트리온 (068270, 정배열+골든크로스)
  - buy1ByMa: true (정배열+거래량+ma20우상향)
  - 1차매수 100 → 50점 ✅ 활성
  - 이유: 정배열+ma20우상향+ma60우상향+거래량+60일고가+지지선+ADX강상승+OBV+라운드

삼성전자 (005930)
  - buy1BySupport: false (obvUp false)
  - buy1ByMomentum: false (ADX DOWN)
  - 1차매수 15 → 9점 ❌ 비활성 유지

=== 효과 ===
- 한미반도체를 MA 없이도 OBV+라운드 조합으로 활성화 (의도)
- 셀트리온은 만점 100 → 50점으로 정배열 편중 완화
- 삼성전자 같은 약한 종목은 여전히 비활성
- 14개 요소가 매트릭스에 골고루 반영
