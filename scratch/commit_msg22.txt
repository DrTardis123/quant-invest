=== H. 매트릭스 점수 기여도 가로 막대 그래프 UI ===
기존: contribs를 배지 형태 (작은 박스)
변경: 가로 막대 그래프 (막대 길이 = 점수)

매트릭스 탭의 buy1/buy2 카드:
- 점수 기여도 영역 (border-top, max-height 160px 스크롤)
- 각 요소: 라벨(64px) + 막대 + 점수(32px)
- 양수 = 초록 막대, 음수 = 빨강 막대
- 점수 큰 순서로 정렬 (.sort((a,b) => b.pts - a.pts))
- 막대 폭: Math.min(Math.abs(c.pts) * 5, 100)%
  - 5점 = 25%, 10점 = 50%, 20점 = 100%

효과:
- 어떤 요소가 매트릭스에 가장 큰 기여했는지 한눈에 파악
- 음수 기여도(매수 자제 신호)도 빨간 막대로 명확하게 표시
- 점수 정렬로 가장 중요한 신호가 상단에 표시
