1. **OBV (On Balance Volume)**
   - 종가 상승 시 +volume, 하락 시 -volume 누적
   - OBV SMA 5/20 추세 비교
   - 강세 다이버전스: 가격↓ + OBV↑ = 매수세 유입
   - 약세 다이버전스: 가격↑ + OBV↓ = 매도 압력
   - buy1: OBV UP +8, 강세 다이버전스 +12, OBV DOWN -5
   - buy2: OBV UP +5, 강세 다이버전스 +8
   - sell1: 약세 다이버전스 +15, OBV DOWN + 수익중 +8

2. **스윙 로우/하이 (Swing Low/High)**
   - 좌우 5봉보다 낮/높은 지점 자동 감지
   - 추세선/지지저항 자동 생성
   - buy1: 최근 스윙 로우 5% 이내 +5, 스윙 하이 부근 -3
   - buy2: 스윙 로우 부근 +5
   - sell1: 스윙 하이 5% 이내 +8 (저항 매도)

3. **Polarity Flip (지지↔저항 역할 전환)**
   - 60일 저점을 종가가 이탈 → 저항선으로 전환
   - 60일 고점을 종가가 돌파 → 지지선으로 전환
   - buy1: 지지선으로 전환된 가격 +5
   - buy2: 지지선 역할 전환 +5
   - sell1: 저항선으로 전환된 가격 부근 +8

4. **라운드 넘버 (심리적 지지/저항)**
   - 가격대별 자동 단위: <1천=100 / 1만↓=1천 / 10만↓=5천 / 10만↑=1만
   - buy1: 현재가가 라운드 넘버 3% 이내 +5
   - buy2: 라운드 넘버 근접 +5
   - sell1: 윗 라운드 넘버 근접 +5 (저항)
