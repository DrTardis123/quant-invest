feat(signal): 매트릭스 5개 요소 종합 + RSI/MACD/피보나치/이격도 추가

매수/매도가 결정에 MA·매물대 외 활용 요소들 웹서칭 후 반영:

1. **ATR (Average True Range, 14)**
   - 변동성 측정 → 손절폭 동적 조정
   - 손절 = max(MA20-10%, MA20-2×ATR) 중 큰 값
   - 변동성 큰 종목: 2×ATR 손절 (노이즈 견딤)
   - 작은 종목: 10% 손절 (보수적)

2. **볼린저밴드 (20, 2σ)**
   - 상단 = 매도 적지, 하단 = 매수 적지
   - 1차매도 후보에 BB상단 추가 (보수적 매도)
   - 1차매수가 후보에 BB하단 추가

3. **52주 고가/저가**
   - 강한 저항(52주고가-3%) / 최후 지지(52주신저가)
   - 2차매수가 = MA60 OR 52주신저가 OR 피보 78.6%

4. **RSI (14)**
   - 30↓ 과매도, 70↑ 과매수, 80↑ 극단 과매수
   - 30→35 반등 = 매수 적지, 70+ = 1차매도 가산
   - 80+ = 2차매도 가산

5. **MACD (12,26,9)**
   - MACD↔Signal 골든/데드크로스 = 모멘텀 전환
   - 0선 위/아래 = 추세 강도
   - sell1: MACD 데드크로스 가산
   - sell2: MACD 0선 하향 가산

6. **피보나치 되돌림 (60일 고점/저점 기준)**
   - 23.6%, 38.2%, 61.8%, 78.6% 레벨
   - sell1: 38.2%/61.8% (저항선 후보)
   - sell2: 23.6% (강한 저항)
   - buy2: 78.6% (매우 깊은 지지)

7. **이격도 (Disparity)**
   - (현재가 - MA) / MA × 100
   - +10%↑ = 과열 (1차매도 가산)
   - -10%↓ = 침체 (매수 적지)

매트릭스 (5개 요소 종합):
- 1차매수가 = MA20 (메인), BB하단, 52주신저
- 2차매수가 = MA60 (메인), BB하단, 52주신저, 피보 78.6%
- 1차매도 = min(MA20+15%, BB상단, 52주고-3%, 피보 38.2%, 피보 61.8%)
  + 최소 +10% 수익 보장 보정
- 2차매도 = min(MA20+30%, 52주고-1%, 피보 23.6%)
  + 최소 +20% 수익 보장 보정
- 손절 = max(MA20-10%, MA20-2×ATR)

검증 (한미반도체 042700 / 셀트리온 068270 / 삼성전자 005930):
- 한미반도체: 1차매수가 207,800 / 1차매도 238,970 (MA20+15%) / 2차매도 270,140 (MA20+30%) / 손절 187,020 (MA20-10%)
- 셀트리온: 1차매수 80점 활성 ✅ (정배열+골든크로스+지지선), 1차매도가 201,591 (보정, MA20+10% floor)
- 삼성전자: RSI 44.85 정상, MACD 0선 아래 (-14,772)

버그 수정:
- RSI NaN: gains/losses 비대칭 길이 처리 (min length)
